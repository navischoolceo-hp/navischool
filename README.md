# navischool-site — 나비스쿨 홈페이지 (GitHub Pages)

htuglobal.com 원본 디자인(헤더 · 푸터 · 메인 섹션 · 서브 페이지)을 그대로 쓰고, 내용만 나비스쿨로 채운 사이트입니다.
이 저장소의 HTML · 스크립트는 **관리자(navi-admin)가 자동으로 만들어 커밋**합니다. 문구 · 이미지 · 메뉴 · 칼럼은 관리자에서 수정하세요.

- `uploads/` — 관리자에서 올린 이미지 · 영상 (지우지 마세요)
- `img/column/` — 칼럼 본문 이미지 · 공유 썸네일
- `img/navi/` — 자동 생성 자리 이미지 · 이름 로고 · 칼럼 카드
- 도메인 연결: Settings → Pages → Custom domain
